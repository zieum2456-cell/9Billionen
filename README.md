# 집필 기록

글을 쓰고 퇴고한 과정을 남기는 게시판형 프로그램입니다. 외부 라이브러리 없이 Node.js만으로 돌아갑니다.

## 기능

- **게시판 목록**: 상태, 제목, 태그, 최신 퇴고일, 남은 퇴고 메모 수, 글자 수를 한눈에 봅니다.
  - 상태별 개수 카드를 누르면 그 상태의 글만 봅니다.
  - 제목·본문 검색, 태그 필터, 정렬(최신 퇴고순 / 최근 수정순 / 작성일순)을 지원합니다.
- **상태 표시**: `초안 작성 중` · `퇴고 중` · `퇴고 완료`. 글 화면에서 바로 바꿀 수 있습니다.
- **최신 퇴고일**: 제목이나 본문을 고쳐 저장하면 자동으로 갱신됩니다. 상태나 태그만 바꾸는 것은 퇴고로 치지 않습니다.
- **퇴고 기록**: 퇴고할 때마다 이전 원고가 날짜와 함께 남아서 언제든 다시 볼 수 있습니다. 퇴고마다 무엇을 고쳤는지 짧은 메모도 붙일 수 있습니다.
- **다음 퇴고를 위한 메모(댓글)**: 글마다 고칠 점을 적어 두고, 반영한 메모는 체크해 둡니다. 퇴고 화면 위쪽에 아직 반영하지 않은 메모가 함께 보입니다.
- **키워드 태그**: 쉼표로 구분해서 입력합니다(예: `단편, 1인칭, 겨울`). 대소문자와 중복은 정리되어 저장됩니다.

## 실행

화면은 `public/writing.html` 파일 하나에 모두 들어 있고, 여는 방법에 따라 저장 위치가 달라집니다.

| 여는 방법 | 저장 위치 |
| --- | --- |
| `public/writing.html`을 크롬으로 바로 열기 (더블클릭) | 그 브라우저의 저장소(localStorage) |
| `npm start` 후 http://127.0.0.1:3000 접속 | `data/db.json` 파일 |
| claude.ai 아티팩트로 열기 | claude.ai 계정의 비공개 저장소 |

파일을 직접 열거나 claude.ai에서 쓸 때는 화면 아래 **백업 내보내기**로 JSON 백업을 받아 둘 수 있고, **백업 불러오기**로 다른 브라우저나 다른 방법으로 옮길 수 있습니다. 백업 파일은 `data/db.json`과 같은 형식입니다.

서버로 띄우려면 Node.js 18 이상이 필요합니다.

| 환경 변수   | 기본값         | 설명                      |
| ----------- | -------------- | ------------------------- |
| `PORT`      | `3000`         | 포트                      |
| `HOST`      | `127.0.0.1`    | 접속을 받을 주소          |
| `DATA_FILE` | `data/db.json` | 데이터를 저장할 JSON 파일 |

모든 글은 `data/db.json` 한 파일에 저장됩니다. 이 파일만 복사해 두면 백업이 됩니다. 인증 기능이 없으므로 기본값처럼 내 컴퓨터(`127.0.0.1`)에서만 쓰는 것을 전제로 합니다.

## 구조

```
server.js        HTTP 서버와 REST API
lib/store.js     데이터 저장소(JSON 파일)와 검증
public/writing.html  화면 (HTML·CSS·JS가 한 파일에 들어 있음)
test/            node:test 테스트
```

### API

| 메서드 | 경로                               | 설명                                  |
| ------ | ---------------------------------- | ------------------------------------- |
| GET    | `/api/posts?status=&tag=&q=&sort=` | 글 목록                               |
| POST   | `/api/posts`                       | 글 작성 `{title, body, status, tags}` |
| GET    | `/api/posts/:id`                   | 글 상세(메모·퇴고 기록 포함)          |
| PUT    | `/api/posts/:id`                   | 글 수정 `{…, revisionNote}`           |
| DELETE | `/api/posts/:id`                   | 글 삭제                               |
| POST   | `/api/posts/:id/comments`          | 메모 추가 `{text}`                    |
| PATCH  | `/api/posts/:id/comments/:cid`     | 반영 여부 변경 `{resolved}`           |
| DELETE | `/api/posts/:id/comments/:cid`     | 메모 삭제                             |
| GET    | `/api/tags`                        | 태그와 사용 횟수                      |
| GET    | `/api/stats`                       | 상태별 글 수                          |
